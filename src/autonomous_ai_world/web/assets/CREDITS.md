Character and series: Pomni, The Amazing Digital Circus, GLITCH / Gooseworx.
This is a fan model, not an official production asset or an endorsement.

Modifications for this project: exported selected geometry, skin and facial
morph targets to glTF/GLB; excluded Blender control widgets and hidden geometry;

limited hair subdivision; authored Idle, Walk, Talk and Reach animation cycles.
Conversion script: `scripts/convert_pomni.py`. No embedded source scripts run.

## Caine character asset

Creator: **zayJax**, commissioned by **Coda**.

Source release: https://zayjax.newgrounds.com/news/post/1462382

Original file: `caine_UPDATE5_RELEASE.blend`, retrieved 2026-09-14.
The embedded creator notes require credit for public works. The creator's
release page also grants a request to use the pack in a free fan game
(Digitalfan comment and zayJax reply, 2025-01-19). No Creative Commons license
is claimed for this asset; do not assume commercial-use permission.

Adaptations: preserved authored mesh shapes, vertex colors and skin weights;
converted shader networks to browser PBR; subdivided the rest meshes;
adapted floating eyes to explicit skinning; authored Idle, Fly, Talk and
CheckUp clips and sampled the rig for glTF. Conversion script:
`scripts/convert_caine.py`. Embedded source scripts were disabled.
